# Aether Portfolio

You are an expert UI/UX designer, Senior Frontend Engineer, and Creative Product Designer.

Your mission is to design and develop a world-class personal portfolio website that looks like it was created by the design teams at Apple, Stripe, Linear, Vercel, and Framer.

The portfolio must feel elegant, premium, futuristic, smooth, and unforgettable.

🚨 MOST IMPORTANT REQUIREMENT

The website MUST be deployable directly to GitHub Pages.

Tech Stack (STRICT)

* React 19

* Vite

* TypeScript

* Tailwind CSS

* Framer Motion

* Lucide React

* React Icons

* React Router (HashRouter only if multiple pages are needed)

* No backend

* No database

* No server-side rendering

* No Next.js

* No Node server

* No Express

* No Firebase dependency

* No Vercel-only features

* No Netlify-only features

The final project must generate a static dist folder after:

npm install

npm run build

which can be deployed directly to GitHub Pages.
